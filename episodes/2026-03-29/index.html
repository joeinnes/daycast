Spanish legislation tracked as a Git repository

Source: Hacker News

A developer has converted the entire corpus of Spanish law into a Git repository, where each statute is a markdown file and every legislative reform becomes a commit. The project tracks over eight thousand six hundred laws stretching back to 1960, all pulled from Spain's official open data API. Want to see exactly how Article 135 of the Spanish Constitution changed during the 2011 fiscal stability reform? Run a diff. It is an elegant use of version control for something that is not code, and it has seven hundred points on Hacker News.

Someone has rendered the original Doom entirely in CSS

Source: Hacker News

Niels Leenheer has built a fully playable version of the original 1993 Doom rendered entirely in CSS, with no Canvas or WebGL. Every wall, floor, barrel, and imp is a div, positioned in three-dimensional space using CSS transforms. The newer CSS math functions like hypot and atan2 handle the projection calculations, and the camera works by moving the entire world inversely around the player. JavaScript manages the game logic, but every pixel you see is pure CSS. It is a remarkable demonstration of how far the language has come.

The argument that Linux is really an interpreter

Source: Hacker News

A blog post making the rounds argues that the Linux kernel is best understood as an interpreter program for initramfs images, in the same way that Python interprets scripts. The author traces an interpretation chain from shell scripts through the dynamic linker, through the kernel, and down to hardware, making the case that what we call operating systems are simply sophisticated interpreters. It is one of those perspective shifts that sounds academic until you realise it changes how you think about system architecture.
